# WP2: Simscape Electrical check against the Python switched model

Generated by `sim_simscape/compare_simscape.py` from `simscape_results.json` and fresh Python switched-model runs. Nothing here has been measured on hardware.

## Independent model

- **Circuit (Simscape Electrical, MATLAB R2025b):** six Ideal Semiconductor Switch blocks (50 mΩ) with integral protection diodes (0.8 V, 50 mΩ). Inductors with series resistance, capacitors, floating AC sources, and a controlled current source for DC1 minus DC2.
- **Solver:** partitioning local solver at a fixed 0.1 µs step (500 steps per switching period), so gate edges and dead time are resolved to 0.1 µs.
- **Controller:** re-implemented in MATLAB Function blocks (`ctrl_step.m`, `pwm_gates.m`) from `CONTROLLER_SPEC.md`, not translated from the Python code. The same author wrote both, so the independence lies in the circuit solver, device models and code path, not in the people.
- **Shared between the models:** the initial state, the orbit-derived references and the LP plan (`scenarios.json`).

## Why the models disagree at 2 µs dead time

Every 2 µs disagreement is a run that both models place within about half a volt of the 190 V bus limit, at phases where the LP finds a trajectory:

| Run | Simscape bus min (V) | Python bus min (V) | Difference (V) |
|---|---|---|---|
| Sweep 0° | 189.94 | 190.48 | -0.54 |
| Sweep 75° | 189.97 | 190.35 | -0.38 |
| Sweep 90° | 189.87 | 190.11 | -0.24 |
| Conventional, θa | 189.75 | 190.11 | -0.37 |
| LP plan tracked, θa | 189.94 | 190.42 | -0.48 |

Halving the Simscape step at the tightest case (90°, 2 µs) gives 189.87 V at 0.1 µs and 189.60 V at 0.05 µs, with the same trip time, so the offset is not step quantisation.

So the Simscape model, which is converged, sits 0.2–0.6 V lower on the bus at these knife-edge runs, and the verdict flips. The physics is the same in both models: with 2 µs of dead time the tuned conventional controller has no bus margin left at these phases. That is a controller-margin finding for WP4, not a contradiction of the LP; no run in either model succeeds where the LP proved infeasibility.

## Limits

- Both switched models use ideal switches with fixed on-resistance; device switching transients, parasitics and the AC sources' common-mode path are WP4 items.
- Agreement between two simulations shows that the result does not depend on one implementation. It is not experimental validation.
